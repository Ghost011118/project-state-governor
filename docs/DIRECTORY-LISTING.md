## English

**Name:** Project State Governor

**Tagline:** Keep long-running agent projects aligned with evidence-backed, canonical state.

**Short description:** An Agent Skill that reconstructs, verifies, and maintains durable project state across conversations, branches, reviews, and research cycles—without inventing product intent or turning project memory into a transcript archive.

**Long description:** Project State Governor helps coding and research agents determine what is authoritative now, what is active or blocked, what has genuinely been completed, what failed and should not be repeated, and what evidence supports the next step. It provides compact and scaled canonical-state layouts, semantic state diffs, completion gates, branch-aware reconciliation, negative-evidence preservation, and strict owner authority boundaries.

## 简体中文

**名称：** Project State Governor（项目状态治理器）

**一句话介绍：** 用可核验的规范状态，让长期 Agent 项目在多轮会话和多分支之间保持一致。

**短简介：** 一个用于重建、核实和维护持久项目状态的 Agent Skill，覆盖会话、分支、审查和研究周期；不会编造产品意图，也不会把项目记忆变成对话归档。

**详细介绍：** Project State Governor 帮助编码和研究 Agent 判断当前权威事实、进行中和受阻事项、真正完成的工作、不应重复的失败方向，以及下一步所依据的证据。它提供精简与扩展两种规范状态结构、语义状态差异、完成门禁、分支感知协调、负面证据保留和严格的所有者权限边界。
